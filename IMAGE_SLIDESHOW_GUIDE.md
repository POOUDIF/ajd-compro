## 📐 Spesifikasi Gambar yang Direkomendasikan

### Ukuran & Format
- **Resolusi**: Minimum 1920x1080 pixels (Full HD)
- **Aspect Ratio**: 16:9 (landscape)
- **Format**: SVG, JPG, atau PNG (SVG direkomendasikan untuk kualitas terbaik)
- **Ukuran File**: Maksimal 500KB per gambar (untuk performa optimal)

### Kualitas Visual
- **Pencahayaan**: Terang dan professional
- **Komposisi**: Horizontal landscape
- **Warna**: Selaras dengan brand colors (#191970, #B22222, #FFFFFF)
- **Style**: Professional, corporate, modern

## 🔄 Cara Mengganti Gambar

1. **Siapkan gambar baru** dengan spesifikasi di atas
2. **Rename file** sesuai dengan nama yang sudah ada:
   - `pic1.jpg` (Corporate Excellence)
   - `pic2.jpg` (Infrastructure Development)
   - `pic3.jpg` (Financial Engineering)
   - `pic4.jpg` (Investment Solutions)
   - `pic5.jpg` (Business Portfolio)
3. **Replace file** di folder `/public/img/`
4. **Refresh browser** untuk melihat perubahan

## 🎨 Tips Optimasi

### Compress Gambar
- Gunakan tools seperti TinyPNG atau ImageOptim
- Target ukuran file: 200-500KB per gambar
- Maintain quality di 80-90%

### Konsistensi Visual
- Gunakan filter atau tone yang sama untuk semua gambar
- Pastikan brightness dan contrast seragam
- Pertimbangkan overlay dark untuk readability text

## 🚀 Setelah Mengganti Gambar

1. **Test slideshow** - pastikan semua gambar muncul dengan benar
2. **Check loading speed** - monitor performa website
3. **Test di mobile** - pastikan responsive di semua device
4. **Backup gambar lama** - simpan sebagai cadangan

## 📝 Catatan Penting

- Slideshow akan otomatis berganti setiap 2 detik
- Gambar akan memiliki overlay gradient sesuai brand colors
- Hover pada slideshow akan pause animasi
- Navigation arrows dan indicators tersedia untuk kontrol manual

## 🔍 Troubleshooting

### Gambar Tidak Muncul
- Pastikan nama file exact match (case sensitive)
- Check file extension (.jpg atau .png)
- Verify file tidak corrupt

### Loading Lambat
- Compress gambar lebih kecil
- Convert ke format WebP jika perlu
- Optimize dengan tools image compression

### Kualitas Buruk
- Gunakan gambar dengan resolusi lebih tinggi
- Check compression ratio
- Pastikan gambar original berkualitas baik
